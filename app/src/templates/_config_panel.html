{{ icon("shield-check", 18) }} Verify SSL {% call setting_help() %}

What it is. Whether the app validates TrueNAS's TLS certificate when connecting over HTTPS.

Off (default). The connection is still encrypted, but the certificate is not checked. Backups work with self-signed certificates.

On. The certificate must be trusted and match the hostname. Backups fail if the cert is self-signed, expired, or invalid.

When to leave off. Home-lab setups with a self-signed TrueNAS certificate (most common).

When to turn on. TrueNAS uses a valid certificate from a trusted CA (e.g. Let's Encrypt).

{{ icon("key", 18) }} Include Secret Seed {% call setting_help() %}

What it is. Whether TrueNAS includes its password secret seed in the config backup.

Off. Encrypted passwords in the backup cannot be restored on a new system.

On (default). The secret seed is saved so encrypted passwords can be restored after migration or disaster recovery.

When to leave on. You may restore this backup onto new hardware and need stored passwords to work.

When to turn off. You only need non-password config, or you deliberately avoid storing cryptographic secrets in backup files.

See How to restore for details on password recovery after migration.

{% endcall %}
{{ settings.include_secret_seed }}
{{ icon("key", 18) }} Include Pool Keys {% call setting_help() %}

What it is. Whether TrueNAS includes pool encryption keys in the config backup.

Off (default). Pool keys are not stored in the backup file.

On. Encrypted pool keys are included — needed to unlock encrypted pools on new hardware after restore.

Security. Treat backups with pool keys as highly sensitive.

See How to restore for migration guidance.

{% endcall %}
{{ settings.include_pool_keys }}
{{ icon("key", 18) }} Include Root Authorized Keys {% call setting_help() %}

What it is. Whether the root user's SSH authorized keys are included in the backup.

Off (default). Root SSH keys are not stored in the backup file.

On. Root SSH keys are preserved for restore onto a new system.

See How to restore for details.
