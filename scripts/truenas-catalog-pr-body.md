## Description

Adds **TrueNAS Config Backup** to the community train.

Schedules and manages downloads of a TrueNAS system's configuration backup via the
`config.save` WebSocket API (SCALE 25.04+ flow using `core.download`), with retention
pruning, run-history logging, optional webhooks, and a password-protected web dashboard.

## Special Notes

- **HTTPS required** for API key auth — TrueNAS revokes keys used over plain HTTP.
- When running on the same box, `https://127.0.0.1` may not work depending on container
  networking; LAN IP fallback may be needed.
- Single-container app, runs as uid/gid 568, uses ixVolume by default for backups and config.
- Optional cron schedule presets; manual-only mode supported.
- Default WebUI port is **30461** (30330 conflicts with mailpit).
- Healthcheck uses bash `http` probe on `/healthz` (image has no curl).
- **Restore** is performed in the TrueNAS UI, not through this app.
